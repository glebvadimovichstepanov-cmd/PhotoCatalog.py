# Проверка версии 2.0.0

Дата: 2026-09-09. База изменений: master, 5448994e49db2a001a0073bf87c9c44be98c1140.

## Выполнено локально

- Windows x64, CPython 3.12.14.
- Pillow 12.3.0, pymediainfo 7.0.1, pytest 9.1.1, Ruff 0.16.6.
- 61 тест pytest прошёл, пропусков нет: `python -m pytest -q` с отдельным basetemp в рабочем каталоге.
- Ruff check и Ruff format --check прошли; git diff --check без ошибок пробелов.
- Установка пакета в отдельное чистое venv из исходников через pip install --no-cache-dir успешна; python -m photocatalog --help работает без pymediainfo и tqdm.
- Диагностика при отсутствующем pymediainfo возвращает код 1 с объяснением.
- MediaInfo.can_parse успешен для установленного Windows-пакета и для явно указанной MediaInfo.dll из исходного репозитория.
- В тестах проверены реальные EXIF JPEG, копирование и повторный запуск, конкурентная запись потоками и отдельными Windows-процессами, настоящий Windows junction, ошибки записи, изменение источника, сохранение mtime и чтение JSON-отчёта.
- Проверены ZIP traversal/Windows-имена, ограничения распаковки, симлинки в архиве, повреждённый CRC, запрет зашифрованного флага, отсутствие публикации частично распакованного архива и очистка TemporaryDirectory.
- Проверены отрицательные/нулевые параметры, пустой/отсутствующий источник, dry-run, ошибки доступа при сканировании, приоритет окружения/CLI, отсутствие опциональных библиотек, передача DLL-пути и код 130 при моделировании Ctrl+C.

Системные каталоги pytest/pip cache оказались недоступны в ограниченной среде исполнения. Проверки завершены с отдельным basetemp в рабочем каталоге и --no-cache-dir; запрос дополнительных разрешений не понадобился.

## Что этим не подтверждается

- Удалённый CI: workflow для Windows/Python 3.12 и 3.13 добавлен; локальный отчёт не утверждает успешный запуск GitHub Actions.
- Не выполнялись отключение питания, физический отказ диска, нагрузочный тест многомиллионной коллекции, проверка сетевых томов и полноценный аудит нативной DLL.
- Работа MediaInfo с коллекцией настоящих видео разных камер и извлечение HEIC/RAW не проверены. Их fallback явно отражается в результатах.
- Прерывание проверено имитацией KeyboardInterrupt на уровне CLI, а не посылкой консольного сигнала во время нативного декодирования.

IDE-файлы удалены из новой версии, восстановление возможно из базового commit; история Git не переписывается. Аудиторский диагностический набор старой версии не включён в тесты нового приложения: регрессии проверяются тестами наблюдаемого поведения в tests/.
